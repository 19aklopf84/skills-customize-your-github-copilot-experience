# 📘 Assignment: Games in Python

## 🎯 Objective

Create a simple Python game that uses user input, loops, and conditionals to make an interactive experience for players. This assignment will help you practice core programming concepts while building a fun project.

## 📝 Tasks

### 🛠️ Build the Game Setup

#### Description
Create a small Python game that picks a hidden word and lets the player guess letters one at a time.

#### Requirements
Completed program should:

- Choose a word from a predefined list using random selection
- Display the hidden word as underscores or blanks for each letter
- Prompt the player to enter a single letter guess
- Show the current progress after each guess
- Keep track of incorrect guesses and remaining attempts

### 🛠️ Add Game Logic and End Conditions

#### Description
Finish the gameplay by checking if the player guessed correctly, updating the word state, and determining when the game ends.

#### Requirements
Completed program should:

- Reveal correctly guessed letters in the hidden word
- Prevent repeated guesses from counting as multiple attempts
- End the game when the player guesses the full word
- End the game when the player runs out of attempts
- Print a clear win or lose message at the end
